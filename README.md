<h1 align="center"> NLW Badge — Crachá Virtual</h1>
<p align="center">Crachá virtual criado durante a trilha Origin da NLW Heat, consumindo a API pública do GitHub.</p>

---

## Objetivo

O projeto teve como objetivo praticar **HTML, CSS e JavaScript** com foco em **integração de API**, desenvolvendo um crachá digital dinâmico.

---

## Tecnologias Utilizadas

- [HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML) — Estrutura da página.  
- [CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS) — Estilização e responsividade.  
- [JavaScript](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript) — Consumo da API do GitHub e manipulação do DOM.  
- [GitHub API](https://docs.github.com/pt/rest) — Fonte dos dados dinâmicos.  

---

## Demonstração

[Acesse o crachá aqui](https://jaquetrevizan.github.io/nlw-badge/)

## Aprendizados

Durante este projeto foi possível praticar:

* Estruturação de páginas com HTML e CSS.
* Consumo de dados de API pública com **JavaScript**.
* Criação de uma página responsiva e personalizada.
* Integração prática com a API do GitHub.
